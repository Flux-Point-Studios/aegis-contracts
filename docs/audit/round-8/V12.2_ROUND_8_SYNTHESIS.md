## Mainnet-blocking findings (MUST close before deploy)

### R8-OFFCHAIN-1 — Dispatcher missing PROVIDER_INDIGO branch (HIGH availability)

- **File**: `api/oracles/dispatcher.py:207-272`
- **Bug**: every Indigo-bound claim / cancel / batch-claim returns HTTP 400 "Unhandled oracle provider: 'indigo'". The dispatcher's switch enumerates Charli3 / Orcfax / AegisSelf but omits Indigo.
- **Impact**: Indigo CDP cover product is non-functional through the API. The R7 report's "single-policy Indigo Claim still works" assertion is wrong for the API path; the validator works, but no caller can reach it.
- **Fix**: single-file dispatcher branch addition. <30 min.

### R8-DRAIN-1 — Partner-address aliasing team-fee bypass (MEDIUM, mainnet-blocking)

- **File**: `validators/pool.ak:715-716, 724-734, 1047-1052, 1059-1065, 1285-1286, 1293-1303` (root primitive at `:510-521`).
- **Bug**: validator checks `team_output_exists && partner_output_exists` as two independent `list.any` calls. Nothing forbids `partner_address == team_address`. When aliased, ONE 16-ADA output satisfies BOTH checks; team is short-changed by `partner_cut`.
- **Impact**: hostile builder with 100k ADA underwrite diverts 400 ADA per cycle. Hits Underwrite, BatchUnderwrite, AcceptCancellation symmetrically. Linear in premium. Mainnet `min_premium = 100 ADA` admits large-premium policies that make this economically meaningful.
- **Fix**: ~3 lines per branch — `expect partner_address != Some(team_address)` (and reject pool_address / policy_validator address too). Plus 3 regression tests. ~1 hr.
- **Why prior rounds missed it**: `partner_address` doc comment at `types.ak:142-157` frames the field as "caller-supplied self-pwn risk." Rounds 4-7 tested bps-cap and Some/None consistency but never address-aliasing.

## Non-blocking findings (worth fixing soon)

### R8-OFFCHAIN-2 — Rate limiters declared but not applied (MEDIUM DoS)

- **File**: `api/server.py:312-348`
- **Bug**: env vars `AEGIS_RATE_LIMIT_BUILD` / `_SUBMIT` are documented; `@limiter.limit` decorators are missing from every endpoint. All endpoints run at default READ rate (300/min).
- **Impact**: trivial Blockfrost quota burn from a single IP. DoS on the build/submit critical path.
- **Fix**: 4-6 decorator annotations across server.py. ~30 min.

### R8-OFFCHAIN-3 — `parse_user_address` doesn't validate network (LOW-MED)

- **File**: `api/tx_build.py:849-870`
- **Bug**: function claims to validate network in its docstring but doesn't. Mainnet deploy admits accidentally-passed testnet addresses (and vice versa).
- **Fix**: 2-line check against `IS_MAINNET` env var. ~10 min.

### R8-OFFCHAIN-4 — `build_sweep_aegis_tx` accepts arbitrary destination (LOW)

- **Saving grace**: signing still requires the in-browser Ed25519 key, so this is XSS-amplification not a standalone vuln.
- **Fix**: validate destination against `wallet.getUsedAddresses()` allowlist. ~30 min.

## What Round 8 verified as CLEAN (positive coverage)

Where prior rounds left things uncertain, Round 8 confirmed:

- **CBOR canonical form** — `mergeWitnessIntoTx` (`frontend/src/wallet/sign_and_submit.ts:220-305`) never round-trips redeemer/datum CBOR; the dedup branch that does call cbor-x re-encoding is dead-code in the standard flow because server-built unsigned txs have `vkey_witnesses = None`.
- **PyCardano cost-model bug** — `_recompute_script_data_hash` workaround (`tx_build.py:518-656`) defensively eliminates the alphabetic-sort bug regardless of deployed PyCardano version.
- **Submit byte preservation** — `_canonical_tx_id` (`tx_submit.py:43-110`) and `submit_tx_cbor(tx_bytes)` (`:283`) preserve wallet-signed body bytes verbatim through submit.
- **OracleProvider Constr indices** — `policies.py:429,445,462,486` align byte-for-byte with `types.ak:60-89` (Charli3=0, Orcfax=1, AegisSelf=2, Indigo=3). V8 ghost-field cross-stack drift was caught + fixed 2026-05-12.
- **All 4 oracle resolvers** pin canonical NFT membership AND script credential (or publisher VKH for AegisSelf).
- **No custom signature verification** in any Aiken validator (zero `verify_ed25519_signature` / `verify_ecdsa` / `verify_schnorr` hits). All auth flows through Cardano's ledger vkey-witness layer.
- **Pool NFT one-shot mint**, **LP mint direction**, **AegisSelf two-layer pin**, **Indigo three-layer handshake** — all sound.
- **Treasury donation field** cannot be zeroed under `premium_positive`.
- **Reference-script substitution** requires BLAKE2b preimage collision (not feasible).
- **V11→V12.2 datum decode** fails closed via field-count mismatch.
